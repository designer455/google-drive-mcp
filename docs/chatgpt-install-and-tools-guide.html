Google Drive MCP

ChatGPT Integration & Complete User Installation Guide

Official User Manual
Target Platform: OpenAI ChatGPT (Plus / Team / Enterprise)
Protocol: Model Context Protocol (MCP) Remote Server
Security Architecture: Per-User Multi-Tenant OAuth 2.0
Executive Summary: This manual provides comprehensive instructions for installing the Google Drive MCP server inside ChatGPT, activating Developer Mode, configuring OAuth 2.0 endpoints, linking your Google Drive with secure single-use linking tokens, and utilizing all 37 Drive tools.

1. Prerequisites

1. ChatGPT Account

ChatGPT Plus, Team, or Enterprise subscription with Custom GPTs / MCP app support enabled.

2. Google Account

Any active Google Account (personal Gmail or Google Workspace) with access to Google Drive.

3. MCP Server Details

Your server URL (e.g. https://<domain>/mcp) and OAuth Client ID & Secret from your admin.

2. Step-by-Step Installation in ChatGPT

Step 1 — Enable Developer Features in ChatGPT

1. Open ChatGPT in your browser and log into your account.
2. Click your Profile Icon / Name in the bottom-left corner and select Settings.
3. Navigate to Settings & Privacy (or Advanced / Developer Settings).
4. Locate Developer Mode or Plugin / MCP Developer Features and toggle it to ON.

Step 2 — Add Custom MCP Connector / Action

1. Navigate to Explore GPTs → Click Create (or go to Settings → Connected Apps / MCP).
2. Under the Configure tab, scroll down to Actions / MCP Integrations and click Add MCP Server (or Create new action).
3. Set the Plugin / App Name:
    Google Drive - [Your Name]  (e.g., Google Drive - Alex or Google Drive).
4. In the MCP URL / Server Endpoint field, enter your deployed MCP endpoint:
    https://<your-mcp-domain>/mcp

Step 3 — Configure OAuth 2.0 Credentials

Select Authentication: OAuth and enter the server OAuth configuration:

  • Client ID: Enter your configured CHATGPT_OAUTH_CLIENT_ID
  • Client Secret: Enter your configured CHATGPT_OAUTH_CLIENT_SECRET
  • Authorization URL: https://<your-mcp-domain>/authorize
  • Token URL: https://<your-mcp-domain>/token
  • Scope: drive  |  Token Exchange: Default (Basic Auth or Post Body)

Click Save & Create MCP. ChatGPT will verify the manifest and load all 37 Drive tools.

Step 4 — Authorize ChatGPT Session & Link Google Drive

1. ChatGPT will open the consent dialog. Click Authorize & Connect to bind your ChatGPT user session.
2. Open a new chat in ChatGPT and invoke your connector:

User: @Google Drive fetch my drive
ChatGPT: Google Drive is not connected for your account. Open this secure one-time link to connect your Google account:
https://<your-mcp-domain>/auth/google/link?code=glink_4f8a912e...
(This link is single-use, expires in 10 minutes, and cryptographically pairs your Drive to this session).

3. Click the link → Select your Google Account on the official Google OAuth page → Click Allow.
4. You will see "Google Drive Connected! You can now close this tab and return to ChatGPT."
5. Return to ChatGPT and repeat your prompt: "@Google Drive fetch my drive". ChatGPT will now list and manage your Drive files in real time!

Executive Trust & Safety Guarantee:
Google Drive MCP operates under a strict Zero-Persistence Architecture. Your personal files, document bodies, spreadsheets, slide presentations, folders, and Google Drive contents are NEVER saved, written to disk, indexed, cached, or harvested on our servers.

10. The Five Pillars of User Data Protection

🚫 1. Zero File Content Persistence

Data streams directly through volatile runtime memory (RAM) over encrypted TLS/HTTPS and is immediately purged from memory once forwarded to your chat session. A hard 10 MB ceiling prevents memory exhaustion.

🔒 2. Multi-User Cryptographic Isolation

Every ChatGPT user connects their own Google Account. Internal opaque subjects (usr_...) isolate every request. User A can never discover, read, modify, or delete User B's files.

🛡️ 3. AES-256-GCM Storage Encryption

Stored OAuth tokens are protected with AES-256-GCM authenticated encryption, 96-bit random IVs, and restricted POSIX 0600 permissions (never web-accessible).

⚡ 4. Single-Use Hashed Linking Tokens

Account linking tokens (glink_...) are hashed with SHA-256, single-use, and expire in 10 minutes. Tokens are never exposed in browser URLs, query parameters, or client-facing responses.

11. Destructive Safeguards & Guardrail Architecture

Built-in Safety Guardrails:
  • Trash vs. Permanent Delete: Standard deletions route safely to Trash (drive_trash_file) and are fully reversible. Permanent deletion requires explicit tool selection and confirmation.
  • Non-Retry Rule on Deletion (SEC-05): Unlike read queries which retry network hiccups, permanent deletion enforces maxAttempts: 1 so dropped packets never cause repeated deletion attempts.
  • Ownership Transfer Strictly Blocked: Any request attempting to assign the owner role is rejected with an explicit security error (OWNERSHIP_TRANSFER_BLOCKED).

12. Instant User Disconnect & Revocation

You maintain absolute ownership and control over your Google credentials at all times:

Method A: Inside ChatGPT

Ask ChatGPT: "Disconnect my Google Drive account". The server immediately calls POST /auth/google/disconnect, revokes the token with Google, and permanently deletes local stored credentials.

Method B: Google Account Security

Visit Google Account Security → Third-Party Apps and click Remove Access. All subsequent requests fail immediately and trigger automatic local credential purge.

13. Compliance & Frequently Asked Questions (FAQ)

Is my data used to train AI models?

No. Data is accessed strictly on demand to fulfill conversational tool requests. The service adheres strictly to the Google API Services User Data Policy, including Limited Use requirements.

What if a one-time connection link expires?

Connection links expire after 10 minutes or upon first click. If a link expires, simply ask ChatGPT to perform any Drive search again; a fresh, valid link will be generated automatically.
