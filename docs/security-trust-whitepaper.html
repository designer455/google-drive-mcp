Executive Privacy Guarantee:
Digitons Google Drive MCP operates on a Zero-Persistence Architecture. Your Google Drive files, document bodies, spreadsheets, presentations, and personal contents are NEVER saved, written to disk, indexed, cached, or harvested on our servers.

1. Overview & Operational Model

Digitons Google Drive MCP functions exclusively as a secure, ephemeral proxy between OpenAI ChatGPT / AI Agents and your authorized Google Drive account. When an AI tool reads or searches a document at your command, data streams directly through volatile runtime memory (RAM) via encrypted HTTPS/TLS and is immediately discarded from memory once forwarded to your active chat session.

2. Architectural Security Controls

🔒 1. Strict Multi-User Isolation

Every user links their own Google Account. There are no shared credentials or master service accounts. User A cannot view, discover, or modify User B's files under any scenario.

🚫 2. Zero File Retention on Server

Drive files are streamed strictly in-memory during active tool calls. No files, metadata caches, or full-text indexes ever touch persistent storage on our servers.

🛡️ 3. POSIX-Restricted Credential Store

OAuth session tokens are saved in restricted directories with strict operating system POSIX permissions: directory mode 0700 and storage files 0600 (owner process only).

⚡ 4. Cryptographic PKCE & Anti-Replay

Built on standard OAuth 2.0 with PKCE S256 (RFC 7636). One-time link tokens expire in 10 minutes, are stored exclusively as one-way SHA-256 hashes, and are destroyed atomically after first use.

3. Total User Control & Instant Revocation

Users maintain absolute ownership and control over their Google account credentials at all times:

Two Instant Methods to Disconnect & Purge Data:
  1. Direct Disconnect in ChatGPT: Asking to disconnect triggers an automated disconnect call (POST /auth/google/disconnect), which instantly revokes tokens with Google and wipes all local credentials from the server.
  2. Via Google Account Settings: You can instantly revoke permissions at any time from your Google Dashboard at myaccount.google.com/permissions.

5. Logging Sanitization & Audit Integrity

The server implements continuous deep-sanitization across all loggers. Confidential values are intercepted and replaced with [REDACTED] prior to output:

  • Google access tokens, refresh tokens, and client secrets are stripped from log records.
  • MCP Bearer tokens, state parameters, and authorization codes are completely masked.
  • No access tokens or secrets are ever exposed in URLs, query parameters, or client redirects.

6. Compliance & Industry Standards

  • Google API Services User Data Policy: Digitons strictly complies with Google's Limited Use requirements. Data received from Google APIs is never used for advertising, nor shared with unauthorized parties.
  • Transport Layer Security: All client and API communication requires TLS 1.3 / HTTPS encryption.
  • Model Context Protocol (MCP) Standard: Adheres to open MCP specifications with explicit tool safety hints (annotating read-only vs. destructive actions).
